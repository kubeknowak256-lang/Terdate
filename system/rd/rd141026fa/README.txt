1. WHAT'S NEW & IMPROVEMENTS
----------------------------
This version includes the following updates based on recent testing:
  * Stability enhancements (the system is now fully stable).
  * Case-insensitivity (commands no longer force lowercase input).
  * System logging features integrated.


2. HOW TO LAUNCH
----------------
Follow these simple steps to start Terdate rd141026fa:

  1. Double-click the "syson.bat" file.
  2. When prompted to choose [y/n], type "n" and press Enter 
     (changing the CD is not necessary).

A terminal window will then open, displaying the following message:
"Welcome to Terdate Operating System". This indicates that you are 
successfully logged into the system.


3. AVAILABLE COMMANDS
---------------------
Type any of the following commands into the terminal:

  program    - Launches the program execution menu.
  programl   - Displays a comprehensive list of available programs.
  shutdown   - Safely shuts down the system and closes the terminal.
  
  tree       - Displays a visual directory tree structure of the 
               current CD (similar to "tree /f /a" in Windows).
  CDS        - Changes the current CDS (CD directory).
  echo vb    - Prompts you to choose a variable and displays its content.
  echo log   - Displays the contents of the "log.txt" system log file.
  clear log  - Clears all records from the "log.txt" file.
  print      - Displays specified text on the screen (e.g., print Hello!).
  cls       - Cleans the screen
