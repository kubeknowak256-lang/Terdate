    Features

    ⚙️

    Bootloader

    Small bios-driven boot process with loader handoff and protected mode initialization.

    ⌨️

    Keyboard & console

    VGA-based text mode, keyboard input, and terminal interaction built for minimal OS workflow.

    📁

    File flow

    A simple filesystem model and batch script workflow designed to be easy to inspect and extend.

    🧠

    Learning-oriented

    The project is ideal for teaching the basics of OS booting, runtime setup, command parsing and memory layout.
